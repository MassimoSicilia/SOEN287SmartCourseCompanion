<h1>📘 Smart Course Companion</h1>

A web-based academic planning tool designed to help university students organize courses, track assessments, calculate grades, and visualize academic progress—all in one place.

This project is developed as part of SOEN 287 – Web Programming at Concordia University (Winter 2026).

<h2>🚀 Project Overview</h2>

University students often juggle multiple courses, deadlines, and assessments. While Learning Management Systems (LMS) provide content, they lack personalized tracking and planning features.

Smart Course Companion fills this gap by allowing students to:

<ul>
  <li>Manage courses and assessments</li>
  <li>Track grades and progress</li>
  <li>View upcoming deadlines in a unified dashboard</li>
  <li>Visualize performance using charts and progress indicators</li>
  
</ul>

The platform also provides instructor/admin tools for managing course structures and assessments.

<h2>✨ Features </h2>
<h3>👩‍🎓 Student Features </h3>

<ul>
  <li>Create and manage a personal account </li>

<li> Add, edit, or delete courses </li>

<li> View assessments (assignments, labs, quizzes, exams) </li>

<li> Enter earned and total marks </li>

<li> Automatically calculate course averages (server-side)</li>

<li> View upcoming assessments across all courses </li>

<li> Mark assessments as completed or pending </li>

<li> Visualize progress using charts and progress bars</li>
</ul>
